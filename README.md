### 🧬 What I work on

I reconstruct biological pedigrees from **ancient human genomic data** using IBD-based kinship inference and runs-of-homozygosity analysis — inferring social and familial relationships in prehistoric populations.

My day-to-day involves building end-to-end aDNA pipelines from raw FASTQ, running population structure analyses, and translating genomic signals into biological narratives.
